# Harness logo sources

Verified on 2026-08-27. The selector uses product marks from first-party pages or repositories; it does not substitute home-made monograms.

- **Codex:** OpenAI blossom displayed above “Codex” on the [current Codex product page](https://chatgpt.com/codex/?app-landing-page=true).
- **Claude Code:** Claude burst from the header of the [Claude Code product page](https://claude.com/product/claude-code).
- **OpenCode:** square logo from OpenCode’s [official brand assets](https://opencode.ai/brand) and [first-party repository](https://github.com/anomalyco/opencode/blob/dev/packages/console/app/src/asset/brand/opencode-logo-dark-square.svg).
- **GitHub Copilot CLI:** current Copilot glyph used on the [GitHub Copilot CLI product page](https://github.com/features/copilot/cli).
- **Antigravity CLI (`agy`):** full-color icon from Google Antigravity’s [official press assets](https://antigravity.google/press).
- **Qwen Code:** square mark from Qwen Code’s [first-party repository](https://github.com/QwenLM/qwen-code/blob/main/packages/desktop-shell/bootstrap/qwen-code-logo.svg).

The vector geometry is embedded locally for Codex, Claude Code, OpenCode, GitHub Copilot CLI, and Qwen Code. Antigravity uses the transparent one-color PNG from the first-party press kit, embedded locally as a CSS mask. This lets every official mark inherit its harness accent and switch color with the selected state without adding a logo box.
